# Wold Mere: Monorepo · Vercel and Render

A monorepo with three apps on two hosts: `campion-is3` and `catmint-swi` on **Vercel**, `woundwort-h4n` on
**Render** (a static site). Static Vite + TypeScript, no framework. The page reads a live list from the shared Supabase test project.
