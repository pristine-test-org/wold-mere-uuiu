Why a shared list helps

One list that everyone can see means nobody has to ask what is next.

When a list lives in one place, a finished task is finished for everybody, and a new task shows up for the whole group at once.

What changes

  • Tasks are added once and seen by everyone.
  • Finished work gets a tick, so it is never repeated.
  • The newest items always appear first.
